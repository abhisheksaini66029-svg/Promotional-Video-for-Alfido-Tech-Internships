# Promotional-Video-for-Alfido-Tech-Internships

**Objective**
Create a short (20–40 second) promotional video advertising Alfido Tech's internship program, using existing brand assets, and produce a matching thumbnail for the upload.

**Requirements**
- Video edited with text overlays and scene transitions
- Alfido Tech branding (logo + brand colors) present throughout
- Deliverables: video file/link + thumbnail image

**Approach**
- Reused the 7 existing branded social post creatives (`post1`–`post7`) as the visual backbone of the video, plus a newly designed intro title card featuring the Alfido Tech logo and the "Learn • Build • Grow" theme line.
- Sequenced all 8 scenes with crossfade transitions.
- Added a persistent lower-third caption bar (mini logo + short animated text overlay) synced to each scene, closing on a clear "Apply Now at alfidotech.com" call-to-action.
- Rendered as a standard H.264/AAC MP4 (1080×1180, ~31 sec) for maximum compatibility across devices and players.
- Generated a matching 1280×720 thumbnail using the brand's logo and exact color palette (cream, navy, red, gold), with a play-button treatment for use as the video's preview image.

**Tools/Stack**
- `ffmpeg` for video assembly, crossfade transitions, text overlays, and encoding
- `Pillow (PIL)` for the intro title card and thumbnail design
- Source assets: brand logo + 7 pre-existing branded post images

**Deliverables**
| File | Description |
|---|---|
| `alfido_tech_promo.mp4` | Final 31-second promo video |
| `alfido_tech_video_thumbnail.png` | Thumbnail image for video upload |
| `Alfido_Tech_Video_Script_and_Storyboard.md` | Shot-by-shot script, timing, and edit instructions |
